 T12 - FRAME TIME TABLE                                                    (R5 owns)
=============================================================================
 HOW: run the program, press V (vsync OFF), press F1, play 10 s; the console prints a line every 300 frames:
   [300-frame average] wall X ms | GPU Y ms | CPU submit Z ms | ...
 "GPU" is 0 on macOS (no timer queries); use wall time there (vsync off).  Press G to switch shadow redraw policy.

 ARITHMETIC TO CHECK YOUR NUMBERS AGAINST (computed, not measured)
   visible pixels at 1280x720: 921,600
   shadow depth samples written per frame when every map is redrawn: 2048^2 + 2 x 6 x 1024^2 = 16,777,216
     = 18.2 x the visible pixel count      (brief: three lights = about 25x; we have two)
   the scene is rasterised about (2 + 6N) times for N omni lights = 14 times at N = 2, from N + 2 = 4 DRAW passes (not 6N + 2).
   Dirty-flag saving: in steady play the shadow passes cost 0 draw passes instead of 4 (a crate push re-draws once).
